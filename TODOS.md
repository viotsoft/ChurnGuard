## ✅ Decided (for reference)

| Decision | Outcome |
|----------|---------|
| ML vs rule-based v1 | Rule-based RFM. ML deferred to v2. |
| Multi-tenancy | Shared tables + Postgres RLS |
| Approval token security | Signed JWT + single-use nonce, 72h |
| Webhook idempotency | Dedup table + X-Shopify-Webhook-Id |
| Klaviyo rate limits | Per-shop queue + backoff + DLQ |
| Service architecture | Modular monolith |
| Tech stack | Rails + Sidekiq |
| Dashboard auth | Shopify OAuth (shopify_app gem) |
| Expired token behavior | Silent expiry + daily re-score |
| Duplicate action prevention | Postgres partial unique index |
| Scoring regression tests | Golden fixture snapshots |
| Scoring batch performance | Bulk SQL per shop (one query) |
| Sidekiq queue config | Named queues: execution(10), notifications(5), scoring(1) |
